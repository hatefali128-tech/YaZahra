## 🌟 درباره پروژه

**قرآن یا زهرا** یک برنامه اندرویدی برای **جستجوی ریشه‌ای کلمات قرآن کریم** است. با این برنامه می‌توانید:

- روی هر کلمه از قرآن کلیک کنید و **ریشه آن** را بیابید.
- تمام آیاتی که از همان ریشه استفاده کرده‌اند را مشاهده کنید.
- ارتباط معنایی کلمات را از طریق ریشه‌های مشترک درک کنید.

این برنامه بر اساس پروژه متن‌باز **[quran-bil-quran](https://github.com/R3GENESI5/quran-bil-quran)** توسعه یافته و به صورت کاملاً آفلاین کار می‌کند.

---

## ✨ ویژگی‌ها

- 🔍 **جستجوی ریشه‌ای**: با کلیک روی هر کلمه، ریشه و مشتقات آن را ببینید.
- 📖 **نمایش آیات مرتبط**: تمام آیاتی که از یک ریشه خاص استفاده کرده‌اند را نمایش می‌دهد.
- 🌐 **آفلاین**: بدون نیاز به اینترنت، همه داده‌ها روی دستگاه ذخیره می‌شوند.
- 🕌 **ترجمه و تفسیر**: (در نسخه‌های آینده اضافه خواهد شد)
- 🎨 **رابط کاربری ساده و روان**: طراحی شده برای همه سطوح کاربری.
